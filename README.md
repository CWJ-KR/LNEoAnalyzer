# LnEoAnalyzer — LiNbO3 전기-광학 특성 분석 프로그램

TiePie Handyscope HS5로 고전압 증폭기(Matsusada AMJ-1B20)를 제어해 LN에 전압을 걸고, 광검출기(Thorlabs DET410) 신호를 자동으로 측정합니다.
측정이 끝나면 사인 함수로 한 번 피팅해 **반파장 전압 Vπ(= w)** 와 **전기광학 계수 r** 을 계산합니다.
장비 없이도 **데모(가상 장비) 모드**로 전체 과정을 시험할 수 있습니다.

## 1. 처음 실행하기

1. Visual Studio(18.x)에서 `LnEoAnalyzer.slnx` 를 엽니다.
2. 처음 빌드할 때 NuGet 패키지(ScottPlot.WinForms, FontAwesome.Sharp, TiePie.Hardware)를 내려받으므로 인터넷 연결이 필요합니다.
3. 시작 프로젝트를 **LnEoAnalyzer.App** 으로 두고 F5 로 실행합니다. 실행 파일은 항상 x64 로 만들어집니다 (TiePie 라이브러리가 64비트).
4. 장비가 없으면 상단의 장비 선택을 **데모 (가상 장비)** 로 두고 [연결] → [측정 시작].

## 2. 장비 연결 구성

| HS5 단자 | 연결 | 용도 |
|---|---|---|
| AWG (신호발생기) 출력 | AMJ-1B20 입력 | DC 오프셋 = 목표 전압 ÷ 이득(100). ±10 V → ±1 kV |
| CH1 | DET410 출력 | 광신호 (optical voltage) |
| CH2 | AMJ-1B20 전압 모니터 출력 | 실제 인가 전압 확인 (모니터 비율 기본 0.1 kV/V = 1/100) |

> **TiePie Multi Channel 프로그램이 켜져 있으면 HS5를 열 수 없습니다.** 이 프로그램을 쓰기 전에 Multi Channel 을 종료하세요.

## 3. 측정 순서

1. **장비 설정** 화면에서 증폭기 이득(100), CH1/CH2 레인지, 모니터 비율을 확인하고 [적용 및 저장]을 누릅니다.
2. **반파장 전압 측정** 화면에서 장비를 고르고 [연결]을 누릅니다.
   - 편광자를 정렬할 때는 **실시간 광신호 보기** 와 **수동 출력**(원하는 kV 직접 출력)을 쓰면 됩니다.
3. 측정 조건(시료, 파장, 온도)을 입력합니다. 이 값은 결과와 함께 기록됩니다.
4. 전압 스캔 조건을 정합니다.
   - 시작/끝 전압과 간격 (±1 kV 안에서만 가능)
   - 안정화 시간 (기본 50 ms), 평균 시간 (기본 10 ms)
   - 단방향 또는 왕복 스캔, 반복 횟수
   - 측정점 수와 예상 소요 시간은 아래에 바로 표시됩니다.
5. [측정 시작]을 누르면 측정점이 그래프에 실시간으로 찍힙니다. 예상·경과·남은 시간과 총 소요 시간이 표시됩니다.
6. 모든 점을 찍은 뒤 `y = y0 + A·sin(π(x − xc)/w)` 로 **한 번만** 피팅해 w(=Vπ)와 표준오차를 표시합니다.
7. 오른쪽 **전기광학 계수** 칸에 n, d, L 을 입력하면 `r = λ·d / (n³·L·Vπ)` 가 바로 계산됩니다. λ는 측정 조건의 파장을 씁니다.
   - 굴절률 칸 옆 **[?]** 버튼을 누르면 n_e / n_o 선택 도움말이 열립니다.
     - 현재 파장의 n_e, n_o 를 셀마이어 식(Zelmon 1997, congruent LN)으로 계산해 보여줍니다.
     - [n_e 적용] / [n_o 적용]을 누르면 그 값이 굴절률 칸에 바로 들어갑니다.
     - 도움말 본문은 `Views/IndexHelpContent.cs` 의 `Markup` 문자열에서 고칠 수 있습니다.
8. 결과는 자동으로 CSV·PNG로 저장되고, **결과 기록** 표에 추가됩니다. 결과 기록 표에는 시료, 파장, 온도, 메모와 피팅 파라미터(±표준오차), Reduced χ², Adj. R², n·d·L, r 이 들어갑니다.

## 4. 피팅에 관해

- 결과는 Origin 결과표와 같은 표현으로 나타냅니다.
  - A > 0, 0 ≤ xc < 2w 로 정규화합니다.
  - 표준오차는 공분산 × Reduced χ² 로 구합니다.
- 엑셀 수동 측정 데이터로 검증했습니다(`LnEoAnalyzer.SelfTest`).
  - 10개 조건 중 7개에서 w 가 Origin 과 소수 다섯째 자리까지 같았습니다. 그중 6개는 표준오차와 Adj. R² 까지 같았습니다.
  - 나머지 3개(1310 nm @34℃, 1550 nm @25℃, 1550 nm @31℃)는 엑셀 데이터에 Origin 파라미터를 넣었을 때보다 잔차가 더 작은 해를 찾았습니다. 엑셀 값과 Origin 이 피팅한 값이 조금 다를 수 있습니다.
- **측정 범위가 반주기보다 좁을 때는 w 를 믿기 어렵습니다.** 예를 들어 1550 nm 는 Vπ 가 2 kV 보다 커서 ±1 kV 안에 반주기가 다 담기지 않습니다.
  - 이때 프로그램이 경고를 띄웁니다.
  - 편광자를 돌려 얻은 최대/최소 광신호로 `y0 = (최대+최소)/2`, `A = (최대−최소)/2` 를 구하고, **y0 고정 / A 고정** 옵션을 켜서 피팅하면 w 를 안정적으로 구할 수 있습니다.
- 피팅 옵션을 바꾸면 이미 측정한 데이터로 즉시 다시 피팅합니다. 계산 시간은 수 ms 입니다.
  - x축: 설정 전압 또는 CH2 모니터 전압
  - 피팅 데이터: 전체 / 정방향만 / 역방향만
  - 포화된 점 제외

## 5. 저장 파일

- 측정 데이터: `문서\LnEoAnalyzer\yyyyMMdd_HHmmss_시료_파장nm_온도C.csv` (+ 같은 이름의 `.png`)
  - 맨 위 `#` 줄에는 측정 조건, 피팅 결과, 전기광학 계수가 들어갑니다.
  - 그 아래는 측정점 표입니다. 열: 설정 전압, 모니터 전압, 광신호 평균/표준편차, 시간, 포화 여부, 피팅 사용 여부
  - 측정점마다 `Fit (V)`(그 전압에서의 피팅값)와 `Residual (V)`(측정값 − 피팅값)도 함께 기록합니다.
  - 오른쪽 두 열 `Fit curve V_set (kV)`, `Fit curve Optical (V)` 는 그래프의 빨간 피팅 곡선(라인) 데이터입니다.
    - 그래프와 같은 범위(±1 kV 측정이면 −3 ~ +3 kV)를 601점(0.01 kV 간격)으로 기록합니다.
    - 측정점보다 행이 많으므로, 아래쪽 행은 측정점 열이 비어 있습니다.
    - Origin·엑셀에서 이 두 열로 선 그래프를 그리면 프로그램 화면의 피팅 곡선과 같습니다.
    - x축을 모니터 전압으로 피팅하면 열 이름이 `Fit curve V_monitor (kV)` 로 바뀝니다.
- 설정: `%LocalAppData%\LnEoAnalyzer\settings.ini`
- 결과 기록 표: `%LocalAppData%\LnEoAnalyzer\history.csv` (프로그램을 다시 켜도 유지)

## 6. 안전 기능

- AMJ-1B20 정격 ±1 kV 를 넘는 전압은 입력 단계와 출력 직전 단계에서 두 번 막습니다.
- 다음 경우 항상 0 V 로 되돌립니다.
  - 측정이 끝났을 때
  - 측정을 정지했을 때
  - 오류가 났을 때
  - 프로그램을 종료할 때
- [해제]를 누르면 0 V 로 내린 뒤 신호발생기 출력을 끕니다.
- 시작 전압처럼 크게 바뀌는 점(0 V → −1 kV 등)에는 긴 안정화 시간(기본 300 ms)을 적용합니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "HS5를 찾지 못했습니다" | USB 연결, Multi Channel 종료, 장치 관리자의 WinUSB 드라이버 (`DriverInstall-WinUSB_v10.0.2.exe`) |
| libtiepie-hw.dll 오류 | NuGet 복원 여부, x64 빌드인지 확인. 그래도 안 되면 TiePie LibTiePie HW SDK 설치 |
| 빌드 오류 `SignalType.DC` | TiePie.Hardware 버전에 따라 열거형 이름이 다를 수 있습니다. `Hardware/TiePieHs5Hardware.cs` 에서 `SignalType.` 뒤의 자동완성 목록 중 DC 항목으로 바꾸세요 |
| 로그의 "CH2 모니터 확인" 기울기가 1 과 다름 | 장비 설정의 모니터 비율 또는 증폭기 이득, AMJ 전면 DC bias 노브가 0 인지 확인 |
| 측정점에 "레인지 초과" 표시 | CH1 레인지를 키우거나 DET410 게인을 낮추세요 (PPT 그래프의 7 V 부근 평탄부 참고) |
| 측정값이 계단처럼 뒤처짐 | 안정화 시간을 늘리세요. 데모 모드에서 안정화 0 ms 로 두면 이 현상을 재현할 수 있습니다 |

## 8. 프로젝트 구성

```
LnEoAnalyzer.slnx
├─ LnEoAnalyzer.App        WinForms 화면 (SpadApp 과 같은 메뉴/제목줄 디자인)
│   ├─ MainForm            왼쪽 메뉴, 화면 전환, 종료 시 안전 처리
│   ├─ Views/ucMeasure     반파장 전압 측정 (스캔, 실시간 그래프, 피팅, r 계산)
│   ├─ Views/ucResults     결과 기록 표
│   ├─ Views/ucSettings    장비 설정, 데모 설정
│   └─ Hardware/TiePieHs5Hardware  HS5 신호발생기 + 2채널 블록 측정
├─ LnEoAnalyzer.Core       장비와 무관한 로직 (스캔 계획/측정 엔진, 사인 피팅, r 계산, CSV, 데모 장비)
└─ LnEoAnalyzer.SelfTest   자체 검증 (엑셀 데이터 vs Origin, 데모 스캔 시간, 안전 제한)
```
